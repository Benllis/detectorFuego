Proyecto de título · Ingeniería Informática

Detección temprana de incendios forestales con visión por computador

FireWatch busca mitigar los daños provocados por incendios, ya sea en lugares urbanos como rurales y poder prevenir grandes catastrofes ocacionadas por este mismo.

Como funciona

De la cámara a la alerta

Cuatro pasos.

01

Captura

Las cámara vinculadas con el program observan a tiempo real si hay indicios de incendios o humo gracias a 2 modelos de IA.

02

Alerta

Si se detecta una alerta de fuego o humo, se le enviara un mensaje a las 3 estaciones de bomberos mas cercanas con una imagen adjunta.

03

Interpretación

En las estaciones de bomberos se puede determinar si existe inicios de incendios, en caso de que se determine que si, bomberos acudira al lugar.

04

Ayuda de Bomberos

Bomberos constara con una ayuda para determinar el peligro del incendio, dependiendo de la gravedad se crearan medidas de mitigación.

Entrenamiento

Resultados de validación

Cada modelo se entrenó por fases, combinando datasets públicos de incendios reales con casos de falsos positivos (nubes, niebla, luces de ciudad) para reducir falsas alarmas.
