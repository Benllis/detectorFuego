Módulo de Cámara — FireWatch

Programa en Python para captura y análisis directo de cámaras en tiempo real.

Versión 1.0 (ZIP)

Este paquete incluye el sistema ejecutable local para conectar cámaras IP o Webcams directamente con el modelo de visión multicámara sin necesidad del navegador.

📦 Descargar Módulo de Cámara (.ZIP)

⚙️ Guía de instalación y ejecución

  1. Descomprimir el archivo: Extrae el contenido de firewatch-camara.zip en tu computadora.
  2. Instalar dependencias: Abre la terminal en la carpeta extraída e instala las librerías necesarias ejecutando:
    pip install -r requirements.txt
  3. Configurar cámaras: Revisa el archivo cameras_config.json para agregar la dirección IP o el ID de tus cámaras.
  4. Ejecutar la aplicación: Inicia el programa ejecutando:
    python main_multicamera.py

💻 Requisitos del Sistema

  • Python 3.9 o superior.
  • Cámara USB, Webcam o Cámara con transmisión RTSP/IP.
  • Conexión a Internet (solo para la descarga inicial).
